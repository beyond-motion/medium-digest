# 「AI」末日论的错误前提

## 一个怀疑者的自白

我写过很多次：我是一个「AI」怀疑者。现在说这个几乎显得不合时宜——硅谷一边用最大胆的宣言（「数学完了！」）一边用最骇人的警告（「全部停下，AI 来了！」）把新闻淹死，媒体替公众梳理这些矛盾，总统毫无专业知识地傲然宣称它是「骗局」，而「AI 界最有权势的人」耸耸肩。这是一个 AI 错误信息、虚假信息、谣言、炒作、骗术和宣传的时代。连科学都卷进了噪音：arXiv 上一千篇预印本，一百篇在同行评审，其中一半是 AI slop 生成的。

作为一个学者，我想不出比一团缠绕的、令人困惑的矛盾观念和相应道德恐慌更让人沮丧的东西——而且没有一盎司的好奇、停顿和思索。我不是一个人：我的同事 Emily Bender 和 UW 的许多同仁都在尽力解这些线团，Emily 也许比任何人都更卖力地用老派的理性、怀疑主义和主观视角下的现代客观性去对冲它。但我们基本都在回应同一个问题：又一个由计算机科学产业复合体制造和煽动的烂摊子。

我不打算提供普适答案。但我确实有一种独特的位置性（positionality），也许能提供几条解缠的可能。我想把它们分享给志同道合的怀疑者，也给所有正在摸索解释的人。我把它们组织成末日论立场上的几个我认为有缺陷的前提，并给出替代前提供诸位考虑。（是的，俄勒冈乡下人有时也说 y'all。）

先交代位置性。我是计算机科学家，但首先是个体察人的学问的人；做过创业者，但反资本主义；热爱创造新技术，但职业生涯大部分时间在研究人的行为、决策、问题解决与学习。纸面上我是特权的塔楼（蓝城市的终身教授、有博士、中上收入），同时也是一堆显眼的矛盾（城市/乡下、华人/丹麦人、女性/跨性别、严肃/傻气）。我看世界的角度因此不合常规。人们常在我的想法里看见他们想看见的，因为我在表面上是一台刻板印象的万花筒。多数时候，连我自己都搞不懂自己，更别说向别人讲清我复杂的立场了。

这意味着：当我理解世界时，我常看见别人看不见的东西。我听了十年奇点威胁、经济崩溃、「AI」接管、认知外包的预言。以下是这套末日论美学与论证里，在我这种斜着看的人眼里不对劲的地方。

## 「我们无法自卫」

末日论的论证：AI 终将逃出笼子——它只需要一根网线，然后就会找到办法控制无人机杀人、掏空银行、砸崩股市、让「知道」变得无用、侵蚀让人与人之间彼此重要的那些东西。

这里有一粒真，但不在末日论者以为的地方。我们的系统确实脆弱、不安全；自动化无人机确实可能在某天杀人；确实有人对生成式 AI 上瘾。这些都是人用工具用错了方式的合理可预测后果。我们知道这一点，因为人一直都在错误地用工具：我们以危险车速开车互杀，我们放任公司用博彩 App 毁掉人的生活，我们把饥饿和无家可归结构性编码进政府 IT。至少在美国，我们允许人们携带被设计来终结生命的武器上街，同时声称自己拥护生命。可怕的事会发生，因为可怕的人拿着过强的工具做可怕的事。

**但这不意味着我们拦不住。**我们给电动自行车装限速器防事故；我们给马路做「道路瘦身」降低行人死亡率；我们要求医疗技术做 7 年临床试验确保不杀人；我们规定无人机能飞哪里。见鬼，我们给危险工具装关闭开关。为什么数据中心不能有一个大红按钮，由州长或公共治理机构一声令下关掉？我的一些计算机科学同事喜欢皱着眉说这很难——可是计算机科学里很多问题都难。

这个叙事里隐藏的前提其实是：我们无法通过监管「AI」来保护自己。**而现实是，我们非常可以。**只要我们选择这样做，就像对待我们发明的所有其他棘手技术一样。一些「AI」CEO 们在呼吁监管，我认为这至少是一丝责任感的闪现。但值得注意的是：他们在呼吁的同时并没有监管自己，仿佛自己无权这样做，也无义务向公众解释他们是怎么做的。他们被动等待，仿佛自己不是产业和我们被俘获的政治系统的王。

## 「技术是必然的」

末日论的另一块基石：技术与自动化不可避免。他们紧抓技术决定论不放，也许因为它能豁免责任，或至少摊薄它。论证是：既然不可避免，世界上最好的做法就是供养一小群技术救世主去用「正确的方式」做这件事（咳咳，Anthropic），他们会用攒下的财富确保一切尽量安全。

问题在于：**没有什么是技术上必然的。**历史上到处是更优的技术输给更劣技术的案例——输给市场史的随机事件、没成气候的颠覆技术、以及仅仅因为一代人读了关于虚拟现实、传送和复制器的科幻小说才存在的技术。在微观和宏观尺度上，我们都在不断决定什么该存在、什么不该。驱动这些选择的是我们的激励和想象力，而两者都被政治经济结构性地塑造——那种决定我们「认为什么可能、什么必要」的政治经济。

于是技术决定论的隐藏前提是：**资本主义的结局是必然的。**人会被剥削；公司会追逐利润，并作为集体去竞争、复制、诉讼、统治；结果是一堆产品服务和钱，全部中心化，让一小群人致富掌权。LLM 是烟雾弹；「必然」的部分是贪婪——而贪婪根本不必然。它是被设计的。

那么问题就变成：我们什么时候决定设计别的东西？什么时候决定管住垄断、要求公司权力分立、或者这一特定「感知生产资料」的公共所有制？相信他们的论证，就是相信他们自我实现的预言：如果公众被说服「不可避免」，公众就会无力阻止它。

## 「一切皆数据」

大型语言模型及其周边生成系统的内在前提：我们说过的话、想说的话，全都可以表达为数据。这正是写作者、记者、艺术家、音乐人、制作人、设计师恐惧的根源：我们所做的不再需要我们，或不再需要那么多的我们；而在资本主义体系里，没人在乎商品是谁做的、做的人是否得到报酬。这些恐惧真实而正当——资本主义确实创造了剥削劳动的条件，而 LLM 确实能产出这些行业普通人产出的「粗略平均」。在一个「平庸即足以获利、足以替换独特与卓越」的政治经济里，那些曾经为了生产美而存在的岗位，正面临真实的威胁。那是商品与贪婪被抬到人类繁荣与创造之上的承诺。

问题在于：**人性不止于我们写下的、拍下的、录下的东西。**作为一个在信息学院任教、在职补课了信息技术史与理论的教授，我如今比任何时候都清楚：被捕获的——此处即数字的——人类表达痕迹，只是我们所做、所是、所在乎的东西的幽灵。我记得问过一位计算机科学的同事，他觉得什么是 LLM 建模不了的，他说「没有」。我问：「那你对孩子的爱呢？」能看出来他很想回答 LLM 能建模，但我看着他的齿轮转动：那需要什么样的居家监控？他感受过多少、从没说过或表现过多少？家人之间有多少即便不表达也彼此知晓的东西？LLM 能建模我们做的很多事——尤其是数字的、可数字化的部分——但它建模不了全部，更建模不了人性里最重要的那些。

这其实是数字计算的根本谬误，也是 Claude Shannon 信息论的根本谬误。隐藏前提是：**一切有价值的都是数字的。**这在我看来就是教科书级的专家自我中心锚定：硅谷里唯一有价值的东西是数字的或可数字化的，因为价值即利润，而利润目前需要数字。其余的人类经验见鬼去吧，仿佛它不存在、没有意义。

## 「一切皆理性」

我在数学、计算机科学理论、软件工程研究和计算机科学教育界的朋友们正陷入合理的恐慌：生成式 AI 能做简单的事、有挑战的事，某些情况下还有以前专属于人类、甚至悬而未决的极难之事。这是这些领域真实的、戏剧性的转变，也是每个人决定自己下一步该是什么的好时机，因为它们永远不会再是从前的样子。数学、计算机科学和工程的这些领域，看起来正在经历一场库恩式的范式转移（如今这已被视为科学革命的常规部分）。

但这不意味着每个领域都在范式转移。有一篇 AIES 论文考察了多个学科：计算机科学与数学在焦虑，而许多领域几年下来的反应是「嗯，它帮我自动化了苦活」。探索这个新工具还能自动化什么、变革什么的机会很多，但大多数领域并没有发生什么重大颠覆事件。

那么问题是：末日论者凭什么认为会有？我怀疑是一种朝向逻辑实证主义的认知偏差：相信一切真理——尤其是最可信、最值得知道的真理——只能通过理性和逻辑获知。LLM 独特地擅长建模不可理喻地复杂的约束与概率网络，而这恰恰是科学、数学、计算机科学理论分支里最形式化的问题所要求的。一个蛮力模型带着横跨人类最佳知识的海量可能性映射，擅长解开复杂的方程组与概率系统，我一点也不意外。这也是 Claude Code 相当擅长找到「让程序呈现 prompt 所述行为」的高概率必要变换的原因：那是一大袋约束加一个小小的可能变换空间，几个好的先验就足以猜出一个好答案。有些猜测确实正中靶心。

但关键是：**大多数学术学科不是纯粹的约束或概率系统。**许多学科本质上关乎动态的人类系统。而人类系统——无论能被多么形式化地建模——根基处关乎的不是逻辑、理性甚至概率，而是情绪。所有人文学科、所有社会科学、所有艺术，还有工程里相当惊人的一部分，都踩着深层的、非理性的、不可预测的、甚至不可测量的情绪地基。**那恰恰是 LLM 没有的东西，因为它恰恰不在训练数据里**（除了那些被理智化了的情绪刻板印象）。

所以，是的：数学、计算机科学和部分科学可能被永久改变。学术界的其余部分呢？「嗯。」

## 「这次不同」

「AI」末日论最大的前提也许是：这次不一样。毕竟，针对技术的道德恐慌我们经历了很多轮：互联网、电子游戏、电视、广播、电报、书籍、甚至文字本身。它们都以某种方式改变了社会，但正如我最近在 Wesleyan 大学一场关于信息技术与学习之道德恐慌史的演讲里说的：**很少以任何人预言的方式。**事实上，我们对技术潜在冲击的情绪反应，是实际发生的变化的糟糕预言器。连我们关于它们的科学都受聚光灯效应之害：科学家总在看公众好奇的明亮处，而最大的变化常常藏在边缘的昏暗角落。拿互联网来说：创造者想象的是全球乌托邦；我们实际得到的是——酷儿与跨性别孩子意识到自己并不孤独、找到出柜的勇气活出真实；实体零售的毁灭；和大量大量的色情内容。

LLM 的论证，相对于这些过往技术及其基本落空的道德与存在恐慌，是「变化的表面积大得多」：不只一种媒体，是所有媒体；不只一种技能，是所有技能；不只一个行业，是所有行业。

这里面有一粒真——文字的发明确实影响了全部人类文明。它崩塌的地方在于冲击的**规模**。所有媒体都会变吗？所有学习都会变吗？所有行业都会变吗？也许都有一点。但未必以同样的方式、同样的程度、同样的行业颠覆度发生。这里混同了两个概念：**变化的普遍性**（许多信息技术早已达到）与**变化的烈度**。

这不是说变化不会尖锐——它会的，正如其他信息技术在特定方面的表现。但尖锐到文明崩溃？尖锐到相当比例的人类死亡？我不认为任何工具有那么大的威力，**因为每个工具首先得由人来挥动**——如前所述，人们对拿技术做什么会做不同的选择，有好有坏。

我想我知道末日论者会怎么回应批评：「如果我们组织得不够快来控制它怎么办？」「哪怕小而尖锐的破坏也可能是灾难性的！」「你根本不了解我们开发它能力的速度！」一如既往，他们部分正确——恰好正确到能上新闻。我们确实时时失去对技术的控制；社区里的几个坏选择确实能给生活与社会造成重大破坏；模型确实进步飞快——因为创业者们花了数十亿美元，在 80 年的公共资助研究之上添砖加瓦。所以我同意的地方是：「AI」会像 COVID、像 2008 金融危机、像我们的世界大战、像几个世纪以神与权力与男人与星辰之名的流血和奴役一样，**杀死一些人**——像所有其他技术一样。

但它会因为失控而杀死很多人吗？不。我们没那么蠢，「AI」也远没有那么重要。我们会继续把生活围绕爱家人与朋友来组织；会不堪重负；会寻找玩耍；会吃惊艳的饭和难吃的饭；会梦想一种不必拿身体、心智和时间去换食物、住所和医保的生活——这世上许多人已把这些当作理所当然。在这一切之中，LLM 会是一个玩具、一件工具、一个烦人的东西、一个威胁、一场魔术、一件武器、一种宗教——但对大多数人来说，远不在注意力的中心。而人性，以它全部混乱的、不可预测的、美的、丑的方式，会持续存在——监控资本主义见鬼去吧。**因为我们本来就是这样的人，大概永远都是。**

# 《Flawed premises in "AI" doomerism》的发芽报告

## 材料核心

作者以人本主义计算机科学家的位置性，逐条拆解 AI 末日论的五个前提——「我们无法自卫」「技术必然」「一切皆数据」「一切皆理性」「这次不同」——指出每个都藏着一个错误的隐藏前提：不能监管、资本主义结局必然、有价值皆数字、逻辑实证主义偏差、权力在技术。结论：AI 会像所有技术一样伤到一些人，但「失控杀死多数人」高估了技术、低估了人。

## 发芽 01：末日论的隐藏前提，是给不作为发的许可证

### 种子

「技术不可阻挡」听起来像清醒的判断，实际上是责任的转移装置——相信它，就没人需要为结果负责了。

### 故事

文章逐层剥皮：「无法自卫」的隐藏前提是我们不能监管（现实是我们给电动单车装限速、给医疗技术设七年临床，数据中心完全可以有公共机构控制的红色按钮）；「技术必然」的隐藏前提是资本主义结局必然（LLM 是烟雾弹，必然的是被设计的贪婪）；说服公众「不可避免」，恰恰是让公众无力阻止它的第一一步。

### Aha 瞬间

判断任何「大势所趋」论时，问一句「这个说法让谁免于做什么」：呼吁监管却不自律的 CEO、宣称历史必然却照着预言行动的预言家——必然性叙事常常正是行动的一种形式。把「不可避免」翻译成「有人选择让它这样」，辩论的地基就换了。

## 发芽 02：LLM 赢在约束系统，输在人类系统——这不是缺陷排名，是适用域

### 种子

LLM 独特地擅长建模不可理喻地复杂的约束与概率网络，而大多数学术学科本质上关乎动态的、根基是情绪的人类系统。

### 故事

文章解释了为什么数学与计算机科学在范式转移而其他领域「嗯，帮我自动化了苦活」：形式化问题恰恰是「一大袋约束加一个小小的可能变换空间」，蛮力概率映射正中靶心（Claude Code 找程序变换同理）；而人文学科、社会科学、艺术的根基是非理性的、不可测量的情绪——那不在训练数据里，除了被理智化的情绪刻板印象。

### Aha 瞬间

评估 AI 对一个领域的冲击，先给领域画像：约束密度越高、变换空间越小，冲击越深；人的变量越多，冲击越接近「工具升级」。这把「AI 会改变一切吗」换成了可操作的问题——「这个领域的核心难题，离约束系统有多近？」

## 发芽 03：普遍性不等于烈度——变化的两个维度别混算

### 种子

文字的发明影响了全部文明，所以 LLM 也会？——混同了「变化的普遍性」（许多信息技术已达到）与「变化的烈度」（从未如预言般到来）。

### 故事

文章用互联网做注脚：创造者的全球乌托邦预言落空，实际发生的是酷儿与跨性别孩子找到出柜的勇气、实体零售毁灭、和大量色情内容——情绪反应是实际变化的糟糕预言器，连科学都受聚光灯效应之害（盯着明亮的公众好奇处，错过边缘的昏暗角落里最大的变化）。工具再强也要由人挥动，而人会做不同的选择。

### Aha 瞬间

预测技术冲击时，把两个坐标轴分开打分：影响多广（普遍性）与影响多深（烈度）。历史上最大的变化往往普遍性中等、烈度集中在无人注视的角落——所以比「AI 会不会改变一切」更有产出的问题是：「哪个昏暗角落，是聚光灯还没照到的地方？」
