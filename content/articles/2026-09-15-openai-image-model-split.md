# OpenAI 把图像模型一拆为二：有意思的不是速度

> 原文：[OpenAI Split Its Image Model in Two. The Interesting Part Isn't Speed.](https://medium.com/@alex9328_99959/openai-split-its-image-model-in-two-the-interesting-part-isnt-speed-8b0b3fd864a7)

---

## 最透露信息的一行，来自客户

OpenAI 于 9 月 8 日发布 ChatGPT Images 2.5。报道千篇一律：更快、更锐、榜一。都对，也全都近乎无意义——每个图像模型的发布都这么说。

作者反复回味的一行来自发布说明里引用的一位客户——Higgsfield AI 的产品负责人。让他团队印象深的不是模型能画什么，而是模型对**「什么不该改」**的把握：你可以做一次有意义的编辑，而不丢失原图的个性、构图与视觉身份。

这句话解释了 OpenAI 随模型更新一起做出、此前从未做过的一个决定。

事实先摆清楚：ChatGPT Images 2.5 第一天就推送给了所有 ChatGPT、ChatGPT Work 与 Codex 用户，覆盖桌面、移动与网页。官方声称四项能力提升——参考保真（reference fidelity）、精确编辑、多轮一致性、以及对复杂指令与版式的更好处理。随模型一起上线了三个产品功能。**而 API 不再是一个模型。**

## 两个模型，按工作负载拆分，而不是按大小

API 侧的 2.5 是两个模型：`gpt-image-2.5-flare` 与 `gpt-image-2.5-sunburst`。

此前所有厂商的拆分都沿同一条轴：大或小、贵或便宜、快或慢——在档位之间做选择，从来都是「穿着技术外衣的预算决策」。

这次拆分走的是另一条路。**Flare 是默认档**：质量高于 GPT-Image-2、延迟约减半，面向创作者内容、产品体验、快速原型、高产量生成。**Sunburst** 瞄准需要在多轮编辑中保持紧密控制的工作流：成品 campaign 素材、精修的产品摄影——它用生成时间换控制。

把这两段描述再读一遍：**Flare 的词汇关于吞吐量，Sunburst 的词汇关于跨轮次的持久。**所以问题不再是「你愿意花多少钱」，而是：**你的工作是在产生一张图，还是在修订一张图？**

这是对「竞争已经移动到哪里」的一次押注：现在任何人都能得到一张像样的第一帧；**差距在第 5 次修订时才打开。**

## 「什么不该改」是更难的问题

精确编辑与多轮一致性在发布说明里是两条；它们其实是同一能力在两个尺度上的样子。单次编辑的尺度：模型只改你要求的部分，其余原封不动——一件商品、一块背景、一行文案，而周围的主体、构图与品牌处理原地不动。多轮的尺度：更早的编辑在后面的编辑中存活下来，每一轮在上一轮之上累积，而不是退化成一团糊。

用上一代做过成套素材的人都知道那个失败模式：第 1 帧很好；到第 4 帧，脸漂了、色调变了，而你找不出是哪一步弄坏的；只能重来。

**这不是图像质量问题，是状态持久化问题——而状态持久化是所有真实生产管线的地板。**没有它，生成图像只是「一次性概念」的来源，不是交付一个 campaign 的方式。

## 五个工作流，各归其位

值得映射的五个工作流：

1. **规模化的产品摄影**——替换主体、锁死光影几何。归 Flare：每次编辑单趟独立。检验它是否真奏效的测试无聊而具体：拍一张主图、生成 40 个变体、检查影子角度是否在 40 张里纹丝不动。上一代悄悄挂在这里——影子漂了几度，图就「假了」，没人说得出为什么。
2. **品牌素材的本地化文案**——只改一行文字、不重排版面。归 Sunburst：撑过第一轮的版式还得撑过第二到第六轮。发过八语种 campaign 的人知道，时间都耗在这里。
3. **角色或代言人连续性**——同一个人贯穿整张镜头清单。归 Sunburst，无可争议。**这就是这个档位存在的原因**，也是此前真正够不着的工作流。
4. **透明底素材**——生成直出免抠 PNG。归 Flare：每张素材独立。发丝和玻璃的边缘能否站得住是开放问题——那是历代模型的共同失败点。
5. **幻灯片与信息图**——层级必须保持的复杂版式。归 Flare，除非稿子要过设计评审循环——那时多轮问题重现，你要换成另一档。

启发式一句话：**单次、高量，去 Flare；凡是会被修订的、或必须与其他东西对得上的，去 Sunburst。**

## 没人报道的那个功能

随模型上线了三个产品功能。两个是便利性的：ChatGPT 内的草图输入、海报与周边的起点模板。第三个是结构性的。

**你现在分享一张图时可以附带它的 prompt。**收到的人可以对自己的素材一键运行同一个创意。本周刷屏所有人时间线的那个「80 年代人像」prompt，靠的就是这个——不是因为它写得好。

Prompt 一直都靠复制粘贴传播：截图、代码块、需要选中再移动的文字。那种摩擦在做真实的功：它过滤掉了大多数人。现在摩擦没了。对以 prompt 为产出的人，这是双刃：好 prompt 传得更远，但 prompt 不再稀缺——**价值从「拥有一个好 prompt」迁移到「理解它为什么有效」。**作者认为这个迁移是好事，尽管他预计一大批靠 prompt 吃饭的账号不会同意。

## 更大的解读

把更宏观的读法直白说出来：三年来，图像生成的竞争问题一直是「第一帧能有多好」——所以每个发布会都缩写成更快、更锐、榜单更高。**这个问题已接近耗尽。**几个模型现在都能可靠地产出好第一帧，它们之间的差异越来越是品味问题而非能力问题。

专门为修订型工作负载拆出一个档位，等于承认：有趣的问题已经移动了。不再是「你能不能生成这个」，而是「你能不能生成这个、然后改其中一处、连改六次、其他东西都不坏」。这是个难得多的难题——也正是「演示用的工具」与「随你交付的工具」之间的分界线。

OpenAI 在这里实际卖的是**控制**：对一次编辑的控制、对一个编辑序列的控制、对复杂版面的控制。如果它扛得住真实生产负载，图像模型就从老虎机向工具挪近一格。如果扛不住，它就是一次挂着版本号的词汇升级。

（作者预告：本周他会给 Flare 做压缩测试，并让一张人像连过 10 轮 Sunburst 编辑。）

# 《OpenAI Split Its Image Model in Two. The Interesting Part Isn't Speed.》的发芽报告

## 材料核心

ChatGPT Images 2.5 的头条是更快更锐，作者却盯住两件事：发布说明里客户的那句话——「一次有意义的编辑不丢原图的个性、构图与视觉身份」；以及 API 第一次不按大小快慢、而按工作负载拆成 flare（吞吐词汇：创作者内容、高产量）与 sunburst（持久词汇：多轮控制、成品素材）。这个拆分是对竞争位置移动的押注：好第一帧已近 commodity，「差距在第 5 次修订时打开」；多轮编辑的失败模式（脸漂了、色调变了、找不到哪步弄坏）本质是状态持久化问题——生产管线的地板。随模型上线的「分享带 prompt」功能则让 prompt 因失去传播摩擦而不再稀缺，价值迁往「理解为什么有效」。

## 发芽 01：commodity 之上，竞争退守到「不改坏」的克制

### 种子

「现在任何人都能得到一张像样的第一帧；差距在第 5 次修订时才打开。」拆分档位本身就是对这个移动的承认——有趣的问题从「能不能生成」变成「能不能生成之后连改六处、其他都不坏」。

### 故事

文章的产品证据链非常具体：四项能力提升里，参考保真、精确编辑、多轮一致性三项全部指向「改而不坏」；客户点赞的也不是生成质量而是「对什么不该改的把握」。上一代的失败模式被诊断为状态持久化问题——第 4 帧的脸漂了却找不出哪步弄坏，只能整个重来。

### Aha 瞬间

当产出能力成为公共供给，产品价值就向它的对偶面迁移——从「做出来」到「改得动而不散架」；这不是图像行业独有，而是所有生成式工具成熟期的共同路径。

## 发芽 02：档位即问卷——「你是在产生，还是在修订？」

### 种子

以往所有档位拆分都是「穿着技术外衣的预算决策」（大小/贵贱/快慢）；这次的分界是一个工作性质问题：你的产出是一次性的，还是要在它身上持续迭代的？

### 故事

五工作流映射给出了可直接抄走的启发式：单次高量（规模产品摄影、透明底素材、信息图）归吞吐档；要修订或要与别的东西对齐（多语种文案改一行、同一人贯穿镜头清单）归控制档。连质检方法都随档位不同：Flare 的测试是「40 张变体的影子角度纹丝不动」，Sunburst 的考验是「第二轮到第六轮版式还活着」。

### Aha 瞬间

好的产品拆分不是把同一个轴切成高中低档，而是识别出「用户到底在问哪个不同的问题」——按预算分档，你优化成本；按工作流分档，你回答命运。

## 发芽 03：摩擦消失之后，稀缺性搬家了

### 种子

「分享图片可附带 prompt、一键复用」这个没人报道的功能，杀掉的是 prompt 传播的摩擦——而那种摩擦一直在做真实的功：它过滤掉了大多数人。

### 故事

作者把这个变化讲成价值迁移：prompt 曾靠截图、代码块、选中复制传播，门槛挡住了绝大多数人，于是「拥有一个好 prompt」本身是资产；一键复用之后好 prompt 传得更远、也更不值钱——「80 年代人像」刷屏靠的是按钮，不是文笔。稀缺性从「占有 prompt」搬到「理解 prompt 为什么有效」。

### Aha 瞬间

任何靠传播摩擦维持的稀缺性都会被一次产品改动清零——护城河的正确位置不在「藏着你的那份文本」，而在文本背后那套可迁移的理解。
